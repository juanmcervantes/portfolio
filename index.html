about_this_site.txt

This is Paper OS: a desktop operating system cut out of construction paper. Inspired by a certain NYC band's website and a certain mountain town in Colorado.

Typefaces: VT323 & Luckiest Guy. Built with Vite + vanilla TypeScript — the window manager is ~150 lines of hand-written TS. No UI framework, no CSS framework, no tracking.
